# WearOSFileManager

WearOSFileManager is a fully-featured standalone file explorer and directory manager for Wear OS smartwatches.

## Features
- Browse internal device directories, system files, and external storage\n- In-app image canvas viewer, text reader, and audio player tools\n- Optimized list scrolling that fits watch bezels natively

## Installation
Install directly via the [WearAppStore](https://github.com/ajimsjames/WearAppUpdater) client on your watch.

## Technical Details
- **Namespace**: `com.ajimsjames.wearfilemanager`
- **Version**: `2.1.0`
